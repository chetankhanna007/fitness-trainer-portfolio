# Fitness Trainer Portfolio 💪

A fully responsive **personal trainer portfolio website** built with HTML5, CSS3, and JavaScript — designed to showcase fitness services, client transformations, and booking functionality.

## 🚀 Live Demo
> Deploying on Netlify — link coming soon

## 🛠️ Tech Stack
- HTML5 (semantic structure)
- CSS3 (Grid, Flexbox, animations)
- Vanilla JavaScript (DOM manipulation)
- Font Awesome Icons
- Google Fonts (Poppins)

## 🎯 Features
- Responsive navigation with hamburger menu (mobile-first)
- Hero section with CTA buttons and animated stats (500+ clients, 95% success rate)
- About section with animated skill progress bars
- Services grid — 6 service cards
- Client transformations gallery with "View More" toggle
- Contact form with input validation
- Multi-column footer with quick links and social icons

## 📁 Project Structure
```
fitness-trainer-portfolio/
├── index.html       # Full page structure
├── style.css        # Responsive styling with animations
├── app.js           # Hamburger menu + transformations toggle
└── assets/          # Images (hero, about, contact, logo)
```
